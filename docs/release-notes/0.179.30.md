# Release 0.179.30

- Date: 2026-04-29

## Summary
- ADR 0464 + ws-0467: SSH retry with backoff + failure classification. New `scripts/ssh_with_retry.py` drop-in wrapper retries ssh up to N times with exponential backoff + jitter, classifies stderr into `auth_failure` / `banner_timeout` / `connection_refused` / `dns_failure` / `network_partition` / `host_key_mismatch` / `unknown`, and writes receipts to `receipts/ssh-failures/`. Composes with the existing `network_partition` gate-bypass reason code. 21 new tests.

## Platform Impact
- New leaf primitive — no existing converge path is changed yet. Wiring into Ansible's ssh_common_args is a follow-up.
- Operator surface: `python3 scripts/ssh_with_retry.py --retries 3 --classify-receipts-dir receipts/ssh-failures -- <ssh args>`.

## Upgrade Guide
- For one-off ssh debugging: replace `ssh ...` with `python3 scripts/ssh_with_retry.py -- ...` to get retry + classification.
