# Release 0.179.35

- Date: 2026-04-29

## Summary
- ADR 0469 + ws-0471: connection.yml SSH key pull from OpenBao. `connection.yml` `proxmox_host.key` and `guest_ssh.key` now accept either a literal path string OR `{vault: <path>, field?: <name>}`. `_materialize_vault_key()` runs `openbao read -field <fld> <path>` and writes the secret to a mode-0600 tempfile under `$LV3_VAULT_KEY_TMPDIR` / `$XDG_RUNTIME_DIR` / `/tmp` for the duration of the SSH command. Schema enforces `additionalProperties: false` on the dict form so typos fail validation rather than silently fall back. 11 new tests.

## Platform Impact
- Backwards compatible — string keys keep working.
- Ready for fleet rollouts where operators don't ship private keys to disk.
