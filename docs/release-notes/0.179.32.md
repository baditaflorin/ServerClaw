# Release 0.179.32

- Date: 2026-04-29

## Summary
- ADR 0466 + ws-0468: converge state diff receipts. New `scripts/converge_state_receipt.py` with `snapshot` + `write-receipt` subcommands. Roles snapshot managed file paths before and after a converge; the script diffs and writes a receipt to `receipts/converge-state/<run_id>.json` with handlers-fired and handlers-notified-but-skipped lists. Closes the "did the reload actually happen" archaeology problem from the 2026-04-28 nginx incident. 9 new tests.
