# Release 0.179.36

- Date: 2026-04-29

## Summary
- ADR 0470 + ws-0472: per-deployment fixture inventory + matrix CI. Three synthetic deployments (`minimal` / `multi-host` / `host-pinned`) live under `tests/fixtures/deployments/<slug>/`, each carrying the full deployment-v1 quartet (`identity.yml` + `topology.yml` + `profile.yml` + `connection.yml`). The parametrised matrix in `tests/test_ws0472_deployment_fixture_matrix.py` validates every contract against its schema for every fixture and asserts cross-file invariants (every guest IP falls inside the identity CIDR, vmids unique within a topology). 28 new tests. Closes the "schema rev breaks deployment X but not Y" class of regression.
- Concludes the 2026-04-29 reliability-improvement sweep — all ten improvements (ADRs 0461 / 0462 / 0463 / 0464 / 0466 / 0467 / 0468 / 0469 / 0470 plus the ws-0465 regression test) are landed.

## Platform Impact
- Test-only; no runtime change.
- Adding a fourth deployment fixture automatically expands the matrix to cover it.
