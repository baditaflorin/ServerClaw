# Release 0.179.23

- Date: 2026-04-29

## Summary
- ADR 0459 + ws-0462: deployment lifecycle CLI parity. New `use`/`new`/`bind` subcommands on `scripts/deployment.py` mirror the existing `make use-deployment`/`make new-deployment`/`make bind-worktree` targets so agents and scripts can drive the deployment lifecycle programmatically without shelling out to Make. Both surfaces produce the same `.local/deployments/<slug>/` data layout. 9 new tests covering slug validation, scaffolding, overwrite refusal, operator parsing, and worktree binding.

## Platform Impact
- No change to existing Make targets — they continue to work.
- New programmatic surface: `python3 scripts/deployment.py {use,new,bind} ...` with typed exit codes (0 success, 2 usage/data error).

## Upgrade Guide
```bash
# Programmatic (agents, hooks, scripts):
python3 scripts/deployment.py new --slug fork --apex fork.example --operator "Op <op@fork.example>"
python3 scripts/deployment.py use --slug fork
python3 scripts/deployment.py bind --slug fork    # in a worktree
```
