# Release 0.179.5

- Date: 2026-04-28

## Summary
- nginx_edge_publication: bump `proxy_buffer_size` to 64k on BOTH the `/oauth2/auth` subrequest and `/oauth2/callback` response locations — fixes 500 Internal Server Error on `ops.<domain>` and other OIDC-protected sites caused by oauth2-proxy header overflow when Keycloak group/role claims are large. ADR 0444 codifies the rationale, the chosen value, and the rule that all oauth2-proxy locations share the same buffer size. Generalises and supersedes the v0.179.2 hot-fix (16k on callback only).

## Platform Impact
- Edge VM peak transient memory rises by O(active_oauth2_requests × 64k); negligible against the edge VM's 4 GB allocation.
- All OIDC-protected sites stop returning 500/502 from oauth2-proxy header overflow; future Keycloak claim growth absorbs without further hot-patches.
