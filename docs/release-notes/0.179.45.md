# Release 0.179.45

- Date: 2026-05-13

## Summary

- **ADR 0483 — bootstrap orchestrator** (`scripts/bootstrap_orchestrator.py`): drives the 14-step gated bootstrap chain; evaluates preconditions/postconditions per step; honors `gates.fail_fast` and per-step `retries`; writes success/failure receipts to `receipts/bootstrap/`; supports `--resume-from <step-id>` and `--resume-last` (reads last failure receipt automatically)
- **Makefile targets**: `make bootstrap`, `make bootstrap-resume`, `make bootstrap-status`, `make bootstrap-dry-run` — all require `_require-deployment`
- **ADR 0484 t5 — live-apply receipt schema** (`docs/schema/live-apply-receipt.schema.json`): formal JSON Schema for live-apply receipts (Draft 2020-12); `verification` array is `minItems: 1`; schema meta-validated by `validate_live_apply_receipt_schema()` in the pre-push gate data-models check
- **42 new unit tests** (229 total passing): `test_bootstrap_orchestrator.py` covers `select_steps`, `build_template_ctx`, `expand_templates`, `evaluate_condition` (file/schema/unknown types), `step_status`, `format_status`, `load_last_failure_receipt`, and `orchestrate` integration (dry-run, resume-from, fail_fast, receipt writing)

## Platform Impact

- no live platform version bump; this release updates repository automation and tooling only
