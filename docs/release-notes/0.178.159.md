# Release 0.178.159

- Date: 2026-04-23

## Summary
- fix(nginx-edge): also filter wildcard SANs from site-local per-hostname cert requests when using HTTP-01 webroot challenge; the previous fix only covered the shared multi-SAN cert but the site-local cert path (for hostnames not in the shared cert) was still requesting *.apps.0fork.com causing certbot to fail

## Platform Impact
- Fork deployments using webroot ACME: nginx-edge now converges cleanly even when service aliases include wildcard subdomains; wildcard aliases are silently dropped from webroot cert requests; DNS-01 required to actually cover *.apps.example.com subdomains
