# Release 0.179.22

- Date: 2026-04-29

## Summary
- ADR 0458 + ws-0461: cert validator multi-deployment auto-detect. New `--all-deployments` flag walks every slug under `.local/deployments/` and validates each in turn. Auto-triggers when neither `--deployment` nor `--fqdn` is passed AND multiple deployments are registered. The pre-push gate's all-lane runner now covers every deployment in a multi-deployment install instead of whichever one happens to be active. 6 new tests. Closes follow-up #3 from the ws-0448 postmortem.

## Platform Impact
- Single-deployment installations are unaffected — the legacy single-deployment path still runs when only one slug is registered.
- Multi-deployment installations get full coverage on every gate run.
- Per-deployment skip: a deployment with a missing or `example.com` placeholder identity emits an `[info]` line and is skipped, rather than failing the whole run.

## Upgrade Guide
- Run `python3 scripts/certificate_validator.py --check-all --all-deployments` once to confirm coverage of every deployment.
