# Release 0.178.148

- Date: 2026-04-16

## Summary
- ADR 0419: PR-based integration flow — all changes to main now go through pull requests with CI checks before merge, replacing direct push-to-main
- ADR 0420: CI release-readiness checks — new GitHub Actions job validates VERSION bump, changelog, release notes, and generated artifacts on PRs with `[release]` in the title
- enhanced PR template with embedded release checklist
- added `scripts/check_release_readiness.py` for local and CI validation of release completeness
- updated CLAUDE.md and AGENTS.md with PR-based workflow instructions

## Platform Impact
- no live platform version bump; this release updates repository automation, release metadata, and operator tooling only
