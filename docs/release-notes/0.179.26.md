# Release 0.179.26

- Date: 2026-04-29

## Summary
- ADR 0461 + ws-0463: atomic receipt write + dangling-receipt gate flag. New `write_receipt_atomic()` helper in `scripts/check_receipt_freshness.py` (tmpfile + fsync + os.replace) eliminates half-written receipts on crash. New `--check-files` flag detects `latest_receipts` entries with no matching `receipts/live-applies/<slug>.json` file — closes the PR #71 class of bug where a slug was registered without committing the JSON. Live signal: 2 pre-existing dangling receipts surfaced (preview_environment, staging_environment, 2026-03-27). 10 new tests.

## Platform Impact
- No effect on existing converges. The atomic-write helper is opt-in for receipt-writing scripts.
- `python3 scripts/check_receipt_freshness.py --check-files` is operator-on-demand for now; pre-push gate wiring is a separate follow-up so the pre-existing 2 dangling receipts don't block unrelated PRs.

## Upgrade Guide
- Run `python3 scripts/check_receipt_freshness.py --check-files` to surface dangling references.
- Receipt-writing scripts can `from check_receipt_freshness import write_receipt_atomic` for safe writes.
