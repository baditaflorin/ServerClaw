# Release 0.178.162

- Date: 2026-04-24

## Summary

- ADR 0438 Phase 2 (complete): mass-renamed `lv3_service_topology` → `platform_service_topology` across all role defaults, task files, playbooks, scripts, and tests (65+ files); inventory fact definition at `inventory/host_vars/proxmox-host.yml` renamed as the root source of truth
- ADR 0438 Phase 4 (shard laziness): removed 7 individual OpenBao artifact path variables from `inventory/group_vars/all/main.yml`; role defaults in `openbao_runtime` already define these paths via `{{ openbao_local_artifact_dir }}/...` and now resolve lazily at task time rather than being baked to absolute paths by the shard generator
- `openbao_postgres_backend` defaults updated to use `{{ openbao_local_artifact_dir }}/postgres-rotator-password.txt` (lazy) instead of `{{ repo_shared_local_root }}/openbao/...` (eager)
- `playbooks/vars/fork-overrides.yml` collapsed from 11 OpenBao path override lines to 1 (`openbao_local_artifact_dir` only); removed stale `openbao_postgres_admin_password_local_file` workaround line

## Platform Impact

- Fork deployments (`make bootstrap` on example.org) no longer require per-artifact path overrides in `fork-overrides.yml` — only `openbao_local_artifact_dir` is needed to isolate the credential store
- Production deployments: byte-identical behaviour (role defaults still resolve to the same absolute paths at runtime)
