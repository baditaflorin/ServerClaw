# Release 0.179.17

- Date: 2026-04-28

## Summary
- ADR 0456 + ws-0456: deployment-aware certificate validation. `scripts/certificate_validator.py` gains `--deployment <slug>`; reads `platform_domain` from `.local/deployments/<slug>/identity.yml` and only checks FQDNs that match. Resolves active slug from `$DEPLOYMENT` / `.local/active-deployment` when no flag is passed; falls back to legacy `.local/identity.yml` for single-deployment installs (byte-identical pre-ADR-0456 behavior). Composes with `cert_lane_pre_existing_failures` (ADR 0451) by adding a narrower `cross_deployment_drift` reason code (max 2-day expiry) in `config/gate-bypass-waiver-catalog.json` that documents the multi-deployment hostname-mapping class of drift specifically. 11 new tests. Closes follow-up #2 from the ws-0448 postmortem.

## Platform Impact
- Single-deployment installations are unaffected.
- Multi-deployment installations stop producing spurious cross-deployment `cert_mismatch` failures on the pre-push gate when the active deployment is correctly registered.

## Upgrade Guide
- `python3 scripts/certificate_validator.py --deployment <slug> --check-all` to scope the validator to one deployment.
- For bypasses: `SKIP_CERT_VALIDATION=1 GATE_BYPASS_REASON_CODE=cross_deployment_drift GATE_BYPASS_DETAIL="<context>" git push origin <branch>`.
