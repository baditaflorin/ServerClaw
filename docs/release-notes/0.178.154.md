# Release 0.178.154

- Date: 2026-04-22

## Summary
- ADR 0385 follow-up — IoC: introduce `platform_config_prefix` (defaults to first segment of `platform_domain`) and parameterize `lv3-` literals in `inventory/group_vars/all/main.yml` and role defaults (linux_access, step_ca_ssh_trust, falco_runtime, proxmox_ntopng, proxmox_security, proxmox_network, postgres_vm, postgres_ha). Strips hardcoded `*-staging-lv3` host names in coolify/librechat/serverclaw/neko playbooks to align with `playbook_execution_host_patterns` source of truth. Zero behavior change on the `lv3.org` deployment; fork deployments auto-derive prefix from their own domain.

## Platform Impact
- no live platform version bump; this release updates repository automation, release metadata, and operator tooling only
