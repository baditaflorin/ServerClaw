# Release 0.178.158

- Date: 2026-04-23

## Summary
- fix(nginx-edge): strip wildcard SANs from certbot request when using HTTP-01 (webroot) challenge; wildcard domains (e.g. `*.apps.example.com`) require DNS-01 and are incompatible with webroot
- fix(nginx-edge): correct Jinja2 regex escaping for wildcard SAN filter (`'\*\.'` not `'\\*\\.'`)
- docs(validation): add TODO spec for digit-leading domain identifier grammar check in validate_repository_data_models.py
- fix(platform): regenerate platform.yml using committed inputs only (example.com placeholders) so pre-push gate passes on machines without .local/ identity overlay

## Platform Impact
- Fork deployments using webroot ACME challenge will now successfully obtain TLS certificates even when service topology includes wildcard aliases (e.g. Coolify `*.apps.` subdomain)
