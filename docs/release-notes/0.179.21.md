# Release 0.179.21

- Date: 2026-04-29

## Summary
- ws-0460: sweep ADR 0457 Phase 2's `host_pinning_guard` role across every service playbook by including it in the shared `playbooks/tasks/preflight.yml` surface. 52 service playbooks (ops-portal, keycloak, gitea, mail-platform, openbao, dify, etc.) inherit the guard automatically — single edit instead of touching every file. Operators can opt out per-play with `host_pinning_guard_skip_in_preflight: true` (documented but not recommended).

## Platform Impact
- Every service `make converge-*` invocation now runs the host-pinning guard before any other preflight check. A deployment-mismatched converge fails fast with a remediation message before any installation tasks execute.
- Single-deployment installations (no `deployment_owner` set on any guest) are unaffected — the guard skips silently.
- Playbooks that don't use `tasks/preflight.yml` (proxmox-host bootstrap, fixture plays, the standalone public-edge playbook which already has the guard wired directly) are unchanged.

## Upgrade Guide
- Set the active deployment slug before any converge: `export DEPLOYMENT=<slug>` or write `.local/active-deployment`.
