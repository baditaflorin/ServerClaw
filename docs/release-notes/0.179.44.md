# Release 0.179.44

- Date: 2026-05-13

## Summary

- **ws-0486 bootstrap foundations (ADR 0483 phase 1):** `config/contracts/deployment-v1/manifest.schema.json` — the single declarative operator input; `scripts/derive_manifest.py` — introspect existing deployment files and emit a draft manifest.yml; `config/bootstrap_steps.yml` — the 14-step gated chain with pre/postconditions per step
- **ws-0485 detect-drift (ADR 0485 t1):** `scripts/detect_drift.py` runs Ansible `--check`, parses PLAY RECAP changed-count, exits non-zero on drift; `make detect-drift playbook=<path>` Makefile target
- **ws-0484 self-check coverage (ADR 0484 t6/t7):** `scripts/lint_bootstrap_coverage.py` CI lint verifying every bootstrap step has ≥1 post-condition; `make lint-bootstrap-coverage` target; post_conditions.yml expanded from 14 to 26 invariants covering openbao.unsealed, gitea, api-gateway, minio, ops-portal, windmill, mail-platform, proxmox host health, and all 6 bootstrap chain steps
- **harbor logging fix (priority 6):** harbor_runtime Ansible role now patches the Harbor-generated docker-compose.yml after `./prepare` to replace syslog driver with json-file rotation (max-size: 50m, max-file: 5) — prevents the circular boot-order dependency that caused the 2026-05-06 five-day Harbor 502 incident
- **Unit tests:** 78→187 tests; new suites for derive_manifest (22 tests), detect_drift (18 tests), lint_bootstrap_coverage (9 tests)

## Platform Impact

- No live converge required for this release
- The harbor logging fix activates on the next `make converge-harbor` run when prepare is triggered; existing Harbor installations are unaffected until then
- example.org: no topology changes
