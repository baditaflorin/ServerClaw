# Release 0.179.19

- Date: 2026-04-29

## Summary
- ws-0458: wire `scripts/host_pinning_check.py` (ADR 0457) into `scripts/validate_repo.sh` as a new advisory lane `host-pinning`. Same pattern as `validate_catalogue_freshness` (ADR 0449) — runs every all-lane gate invocation and reports drift without blocking. Skips silently when `.local/deployments/` is absent (CI runners). The lane was already in `validate_repo.sh`'s help string and lane dispatcher; this PR also flips it on as part of the all-lane runner.

## Platform Impact
- New `bash scripts/validate_repo.sh host-pinning` lane available.
- `bash scripts/validate_repo.sh all` now includes the host-pinning audit (advisory).
- No effect on installs that don't opt into `proxmox_guests[*].deployment_owner`.
