# Release 0.179.27

- Date: 2026-04-29

## Summary
- ADR 0462 + ws-0464: topology pre-commit schema hook. New `scripts/validate_topology_schema.py` validates topology YAML against `config/contracts/deployment-v1/topology.schema.json`. Pre-commit hook `validate-topology-schema` fires on `inventory/host_vars/proxmox-host.yml`. Closes the 2026-04-28 topology-shape class of bug at commit time (the bug ws-0448's runtime auto-fill papered over). 11 new tests.

## Platform Impact
- New pre-commit hook fires on the canonical proxmox-host.yml only — no effect on PRs that don't touch it.
- Operator-facing CLI: `python3 scripts/validate_topology_schema.py` walks committed proxmox-host.yml plus `.local/deployments/*/topology.yml`.

## Upgrade Guide
- Run `python3 scripts/validate_topology_schema.py` once after upgrade to confirm the canonical topology validates clean.
