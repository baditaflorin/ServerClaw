# Release 0.179.29

- Date: 2026-04-29

## Summary
- ADR 0463 + ws-0466: post-converge / on-demand health-probe runner. New `scripts/run_health_probes.py` reads `catalog/services/<svc>/service.yaml::health.liveness` (HTTP/TCP), runs the probe live, and writes a per-probe receipt under `receipts/health-probes/<slug>-<ts>.json` using the ADR 0461 atomic-write helper. CLI: `--service <slug>` (repeatable), `--all`, `--timeout`, `--receipts-dir`, `--json`, `--no-receipts`. 8 new tests.

## Platform Impact
- Operator-on-demand: `python3 scripts/run_health_probes.py --all` checks every service in the catalog.
- Wiring into per-role converge tasks and a `make doctor` signal that reads the receipt format are explicit follow-ups.
